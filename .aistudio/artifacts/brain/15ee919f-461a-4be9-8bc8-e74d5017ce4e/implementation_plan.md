# 全系统 UI 布局统一与交互闭环优化方案

针对全系统 10 个模块的巡检发现，本次从**导航稳定性、跨页面头部规范、城市状态联动、报错操作闭环**四个维度进行系统级打磨：

---

### 1. 固定左侧导航栏，消除切换页面时菜单项消失跳动
- **现状痛点**：切换到「薪资核算」或「价格审批」时，左侧栏底部「归档与配置」分组中的 `扣款规则` 与 `模板中心` 被条件隐藏，导致左侧菜单项在 8 项与 10 项之间来回跳动。
- **优化方案**：
  - 在全系统任意视图下，始终完整展示左侧 3 大分组共 **10 个导航项**（`风神数据`、`蓝橙数据`、`白泽商翼`、`小象灯塔` / `专项报表`、`薪资核算`、`价格审批` / `任务中心`、`扣款规则`、`模板中心`）；
  - 当打开「扣款规则」或「模板中心」面板时，侧边栏同步高亮对应菜单项，关闭面板后恢复当前主工作区菜单高亮，消除视觉认知割裂。

---

### 2. 精简「价格审批」与「任务中心」重复标题及外层白框，修复空状态断裂
- **现状痛点**：
  - 「价格审批」与「任务中心」在顶部全局面包屑下方又套了一层大白框并重复印了大号黑体标题（`蓝橙价格审批`、`任务中心`）与副标题；
  - 「价格审批」在未读取到待办时，「本人待审批」卡片内的 **「城市」「结算月份」** 标题下方完全空白，显得像排版断裂。
- **优化方案**：
  - **合并单行顶部工具栏**：移除「价格审批」与「任务中心」中与面包屑重复的二级大标题及多余外层白框套娃，将模式切换（`批量审批 / 待审每日价格导出`、`全部 / 进行中 / 待处理 / 已完成`）与右侧操作按钮合并为清爽的单行顶栏；
  - **收敛价格审批空状态**：当尚未读取到待办城市与结算月份时，不再裸露空的「城市」「结算月份」小标题，而是展示紧凑的一行空状态说明框，版面整洁连贯。

---

### 3. 统一「小象灯塔」`01 处理城市` 与右侧执行核对栏联动
- **现状痛点**：「小象灯塔」左侧 `01 处理城市` 胶囊写着 `已选 0 / 10`，但右侧核对栏固定显示 `可访问全部城市`；即便用户在左侧勾选了具体城市，右侧依然不变，造成“勾不勾选城市到底有没有用”的困惑。
- **优化方案**：
  - **01 标题胶囊明确默认规则**：与「蓝橙数据」保持一致，未选城市时 `01 处理城市` 胶囊显示 `默认全部城市（已选 0 / 10）`，已选时显示 `已选 X / 10`，并提供 `清空城市` 快捷按钮；
  - **右侧执行栏实时联动**：未勾选城市时右侧显示 `可访问全部城市`；一旦用户在 `01` 勾选了具体城市（如 `上海、深圳`），右侧「处理城市」立即联动展示已选城市名称及数量（如 `上海、深圳（2城）`），实现所见即所得。

---

### 4. 优化「专项报表」布局与控件视觉，并为未登录提示增加「立即登录」按钮
- **现状痛点**：
  - 「专项报表」左栏重复印了 `专项报表` 标题，右侧表单中原生 `<select>` 与自定义下拉混用；
  - 「价格审批」与「站点扣款配置」在未登录平台时只显示红字报错，没有直接登录入口。
- **优化方案**：
  - **专项报表视觉统一**：移除左栏重复的 `专项报表` 小标题，统一右侧下拉框、月份快捷按钮与底部操作栏的圆角、边框和留白比例；
  - **报错条一键登录闭环**：在「价格审批」（`请先登录蓝橙，再读取本人待办`）与「站点扣款配置」（`请先完成平台登录后刷新`）的提示条右侧，直接内联 **「立即登录平台」** 按钮，点击即可就地唤起平台登录弹窗。
