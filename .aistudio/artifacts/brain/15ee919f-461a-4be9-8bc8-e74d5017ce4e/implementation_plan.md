# 实施方案：3 项 UI 与交互细节优化

已确认您的业务偏好：
- **03 资料选择区域**：采用「分类快捷过滤标签 + 紧凑视图切换」精简纵向视高。
- **任务中心失败重试**：明细行直观提供「重试单城」，并在头部支持「一键重试全部失败城」。
- **执行核对栏**：未满足执行条件时，点击底部校验提示条自动平滑定位并脉冲高亮对应步骤。

---

## 优化一：03 资料选择区域视高优化（分类快捷过滤 + 紧凑视图）

### 1. 业务分类快捷过滤标签 (Filter Tabs)
在「03 选择资料」工具栏右侧提供分类切换药丸标签：
- **全部**（共 12 类）
- **发薪核心**（骑手出勤明细、配送费、违规扣款、月度 UB 账单、骑手风神绑定）
- **风控稽核**（欺诈单、问题单）
- **基础人事**（邀请记录、运单数据、骑手数据明细、骑手信息导出、物资租用登记）

切换分类时仅展示目标子集，右侧「全选该分类资料」与选择计数保持独立联动。

### 2. 紧凑视图与标准视图切换 (View Mode Toggle)
在资料区域提供「视图切换」控件（标准卡片 / 紧凑磁贴）：
- **标准卡片视图**：保持现有卡片，含标题、副标题说明与业务标签。
- **紧凑磁贴视图**：采用 36px 扁平紧凑卡片，缩减文本冗余，使 12 类资料单屏完整呈现，消除滚动负担。
- 用户视图选择记忆在本地（`localStorage`）。

## 优化二：右侧「执行核对栏」引导式平滑定位与脉冲高亮

### 1. 动态可点击报错提示
- 当未选择城市时，执行栏底部展示「⚠️ 请至少选择 1 个处理城市」，光标变为 pointer，带有下划线与「点击直达」指引。
- 当已选城市但未选择资料时，执行栏底部展示「⚠️ 请至少选择 1 类资料」，光标变为 pointer。

### 2. 平滑滚动与瞬态脉冲动画
- 点击城市提示：页面平滑滚动至 `01 处理城市`（`#step-01-cities`），并在卡片外框应用 1.5 秒的蓝色呼吸高亮动效（`wb-field-pulse-highlight`）。
- 点击资料提示：页面平滑滚动至 `03 选择资料`（`#step-03-datasets`），并在卡片外框应用呼吸高亮动效。

## 优化三：任务中心单城市失败切片重试与一键全部重试

### 1. 失败汇总区增加「一键重试全部失败城」
在任务详情的状态条与恢复提示区中，如果任务包含失败或未完成条目：
- 顶部醒目呈现：`一键重试全部失败城市 (共 N 项)`，点击后自动批量提交所有失败条目。

### 2. 明细行直观「重试单城」独立操作
- 针对失败或中断的单项记录（如 `广州 · 违规扣款`），行内原本隐藏在折叠项内的「继续/重试」动作提升为外露的快速操作按钮：
  - `重试单城 (广州)`：点击仅针对当前城市和当前数据项发起补采，避免重新跑全量已成功的其他城市。
