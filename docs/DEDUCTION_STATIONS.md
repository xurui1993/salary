# 扣款配置中的平台站点

在「扣款规则」点击「从平台新增站点」，或在已有站点下点击「从平台选择」。

- 风神：先获取城市列表，选择后台城市，再获取站点。
- 灯塔：先获取当前账号及合作商授权的站点目录，可再按城市查询。
- 支持按站点名称、编号或城市搜索；同名城市显示编号，同名站点保留各自编号。
- 选中后只填入配置草稿的城市、团队名称、团队 ID。检查扣款后点击原保存按钮生效。
- 仍可手动新增或维护历史站点。目录没有返回某个站点，不会删除已有配置。

目录读取复用已有平台登录。需要登录时点击「平台登录」，完成后重新获取；切换账号会清空旧目录并保留配置草稿。目录缓存五分钟，可点击「刷新目录」主动更新。

风神读取当前授权的物流合作商城市及站点，查询结束后还原原城市；灯塔使用官方静态站点目录，不依赖订单、骑手记录或看板登录。灯塔的业务城市与管理城市分别保留，配置使用业务城市，不猜测城市简称。

不会自动替换历史配置、扣款金额、自定义字段或冻结批次。平台选择仅更新现有的三个元数据字段，不新增会被误识别成扣款列的来源字段。当前核算按名称匹配，平台选站会拦截同名或按现有“新专送”规则归一后等价的配置，提示维护原记录；核算规则本身保持原样。

后端只读接口：`GET /api/workbench/deduction-stations?platform=fengshen|xiaoxiang&city=<后台城市编号>&refresh=1`。城市可留空；风神空城市只返回城市目录，灯塔空城市返回全部授权目录。需要现有工作台访问权限。站点、城市编号均以字符串传递，保留前导零和长编号。
