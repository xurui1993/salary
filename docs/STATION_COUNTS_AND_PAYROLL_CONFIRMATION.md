# 城市站点数与核算前扣款确认

城市选择处展示当前账号后台目录中的站点数，按站点编号去重。目录异步读取，最多缓存五分钟，可手动刷新；未完成或失败显示“待同步”，与真实零站点区分。风神按城市顺序查询并还原原城市；遇采集忙则稍后重试，恢复未确认时停止并提示。换账号清除原目录。灯塔目录不代表知了/MOA验证已完成。

扣款配置默认展示后台城市和站点，按平台、城市编号、站点编号保存金额。原 `data/config.json` 保留；匹配的旧金额仅作待核对候选，不会静默确认。后台新增站点保持待配置，不能自动当成零扣款。默认保存使用原有管理员权限，保存前检查版本，旧版本保存在 `data/deduction_profiles/history/`，不自动删除暂不可见的历史站点。

闪购自动采用“上传申请表 → 确认扣款并自动执行 → 下载结果”。上传后先按申请名单核对扣款，确认后自动获取配送费、支付绑定及其他资料；后台校验账单归属无差异时沿用本次已确认金额自动核算，有差异时暂停等待人工确认。闪购手动及灯塔核算保留在“更多”入口，资料就绪后确认扣款。填写金额，或明确确认本站零扣款；空白金额不允许开始核算。阈值列 `_maxDays` 的空白继续沿用原计算口径，不会被填零改变口径。灯塔费用按原引擎源列显示对应名称，不新增重复费用。

申请名单只读取“申请名单”子表，可识别团队名称及可选站点编号。与账单存在差异或无法核对时，需要逐项人工确认；无法唯一匹配后台站点时阻止核算。后台城市名称与申请城市不一致，可人工选择当前目录城市作明确映射。需纠正归属时修改原资料并重新上传，不自动改写源表，不更改原核算归属与金额算法。清单只将现有引擎支持的费用及天数阈值列作为可编辑核算项，其余历史扩展字段原样保留。

勾选保存默认金额后，后续同平台、同城市及站点编号可沿用；不勾选则仅用于当前批次。确认记录绑定申请、账单校验信息与扣款版本，核算开始前再次校验。资料或金额变化后重新确认；开始核算时冻结本批次规则。历史已冻结的批次不能通过确认接口改写金额。

灯塔采集页面不展示、不提交“取分离站点”筛选；风神原有业务规则保留。

闪购自动不再提供补传 Excel 或跳过支付绑定入口。缺少平台登录或获取失败时暂停，原任务重试依照已有导出回执恢复，不盲目重复提交。核算失败后可按冻结规则重试，每次核算使用独立 attempt 目录，保留之前的文件。

任务中心支持下载、报表、核算、价格审批及价格导出的停止与移出。停止在安全检查点生效，进行中的任务确认停止后才移出；已发出的平台审批不撤回。移出为共享列表整理，可恢复显示，不删除文件、申请表或处理回执。服务进程中断的核算标为中断，保留冻结规则与文件，不冒充已完成。

## 城市默认金额与取分离关联

扣款采用平台、城市编号、站点编号区分。站点单独配置优先于城市默认；新站点可沿用已明确保存的城市金额。城市金额在本批次确认时展开为明确的站点行并冻结，之后调整城市默认不会改变已开始的批次。零扣款仍需明确确认。共享默认配置保存在原 profile 文件的 cities 字段，旧 entries 与历史备份保留。

一键同步只填写同城未配置且未编辑的站点；支持勾选目标站点及撤销，不复制站点身份，也不覆盖已保存的单独金额。

自动核算申请名单含取分离站点时显示提示，由用户启用资料关联。目录查询同城物流服务商，按真实站点编号归入所选城市的扣款目录，保留实际合作商编号；查询结束恢复原合作商。普通与取分离分别创建持久下载任务，恢复沿用各自原回执，全部成功后按相同表头合并。原件及哈希保留在本批次 evidence 目录，不混入引擎扫描目录。共享商翼子表仅在内容一致时保留一份，变化则暂停，不能混用版本。此机制不根据相似名称猜测站点编号。

三种核算方式在同页标签切换，扣款确认直接在当前页展开；界面名称使用“小象超市”，后台标识 xiaoxiang 保持兼容。

## 本人审批范围

价格审批从官方本人待办列表读取可办理的流程及其业务表头，排除非本人节点、已提交及待核实的重复节点，不使用基础站点或历史价格目录填充审批筛选。城市、月份支持多选，站点随范围联动；可跨页勾选当前范围，每批上限200条。读取筛选范围不读取骑手价格明细，不执行审批。预览及提交仍执行原有账号、节点、版本和幂等校验，不自动审批。

## 扣款确认下一步引导

底部操作栏按阻塞条件依次显示“启用并关联取分离站点”“处理站点关联”“补齐扣款金额”“核对归属差异”，全部就绪后才显示“确认扣款并自动执行”。非加载状态可点击定位处理，不用灰色按钮掩盖原因。最终按钮本身承担明确确认，零扣款及账单归属差异仍需单独确认。

目录更新、取分离重同步与人工关联保留同一身份站点的已编辑金额和城市草稿；填写完整的城市金额自动应用到未配置或沿用城市规则的站点，保留独立站点金额和用户编辑草稿。

人工关联只可选择本次后台城市的真实站点，不能越过申请明确提供的站点编号。区分缺失、同名候选和编号冲突。关联仅记入本批次，原申请、后台名称与共享默认不变。核算将已确认的名称别名展开为相同金额及相同后台编号的批次规则；不同身份的同名规则冲突会阻止核算。关联有审计记录并绑定输入签名，开始核算后不可更改。未做关联的旧批次继续使用原签名格式。

## 下载清单与本次城市读取

薪资核算直接按本次城市读取真实目录，不需要全城市扫描结束；同账号更新期间保留已核实的城市站点，账号变化不复用旧目录。全局城市站点数量仍可后台补齐。扣款清单遇到排队会有界限地自动重试；读取成功后自动显示金额，读取失败明确提示登录或连接处理。申请摘要立即展示，未核实的站点数显示待核实。

自动执行期间默认展示七项核算资料清单。进度来源为持久子任务的每项状态和阶段，即使整批百分比未变化，单项状态变化也立即发布。普通与取分离资料在同一项目下合并分组，重试沿用相同组，避免重复计数。区分待下载、下载中、平台生成、待登录、已下载待校验、校验中、已完成和失败。已下载与已校验分别计数；只有输入快照通过原有校验才可核算。前端不生成下载百分比，显示当前步骤与本批次实际起始时间；刷新页面沿用后台已保存进度。
