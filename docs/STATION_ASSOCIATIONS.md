# 站点批量关联

扣款确认中的“站点关联”使用紧凑表格，默认只显示未完成项。列表每次展示 20 行，表格高度受限，支持搜索、仅看异常、勾选推荐结果、批量确认以及多个申请名称映射到同一个实际站点。推荐名称不会自动授权核算；必须勾选并确认。可以在“全部”中查看和修改已关联项，未保存的修改会阻止直接开始核算。

## 身份与复用

- 唯一且同城、同类型的站点编号可直接匹配，即使申请名称不同。名称别名仅写入本批次的核算规则，保留原申请和后台标准名称。
- 人工确认可选择保存为历史关联。历史数据独立于扣款金额，保存在 `data/station_associations/<platform>.json`；覆盖前保留 `history` 副本。
- 关联按平台、官方账号身份、城市编号、原始申请名称和站点类型复核。仅保存身份摘要，不存储登录凭据。
- 风神从已有只读身份查询获取明确的用户标识；小象使用官方当前供应商和操作账号。如果平台未提供稳定身份，保守限制在同一登录会话复用，重新登录后需要再次确认。
- 历史站点编号失效、类型变化、同名多站或编号冲突时重新确认，不能悄悄改绑同名新编号，也不能把取分离站点关联到普通站点。

## 业务边界

保存接口再次校验当前目录版本、关联版本、城市、类型及来源编号，并保留操作记录。批量请求中有一个非法目标时整个请求拒绝，不部分写入。下载后重新核对实际账单归属；已确认的关联分配发生变化时暂停并要求重新确认，保留已确认金额及原始文件。

本功能不改变扣款公式，不将名称推荐视为财务验收，也不自动修改源申请表。界面验证使用合成数据拦截写入，不执行真实薪资核算、导出或审批。
