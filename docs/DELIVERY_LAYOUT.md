# 生成与下载目录

资料下载、业务报表、薪资核算、每日价格导出和审批回执统一交付到配置的生成根目录（默认 `outputs/fengshen_downloads`）。成品先按任务创建日期（北京时间，YYMMDD）分入日期目录，每个任务再占一个子目录，如 `outputs/fengshen_downloads/261106/配送费_泉州_2026-10-01至2026-10-31`；成品及 `文件清单.csv` 直接平铺。任务目录名为「业务_城市_数据期间」，缺失项自动省略；同名任务重跑时追加生成时间和短编号。文件名保留城市与业务范围。不同任务不覆盖，同名文件附稳定编号。已登记的历史目录保持原位，不迁入日期目录。

原始来源、处理输入、凭据和诊断留在 `backend/.local_downloads/workspaces` 等内部工作目录。任务中心“复核资料”提供平铺的原件 ZIP，并附来源映射及 SHA256 清单；同字节原件只导出一次。原件和经过筛选的实际处理输入分别保留，来源包不代替处理规则核验。

`backend/delivery_store.py` 持久化文件编号到成品位置的映射，并在移动前写日志。原文件移动后下载、恢复仍使用相同编号。历史版本移入内部 history；用户手动修改的成品不会被自动覆盖。领取时校验大小和 SHA256，打包中再次校验。目录中自行放入的额外文件不进入结果包。

薪资成品只通过当前工作区准备记录领取；旧的结果下载链接转发到同一认证入口，不开放任意目录读取。审批回执生成仅读取已存在的审批记录，不提交审批或重放官方请求。

新兼职薪资核算使用专属交付规则：每模板仅交付工资表、蓝橙无单价&未绑名单两份 Excel，目录和下载包不生成 `文件清单.csv`。复核清单内嵌工资表，摘要和校验码保存在内部批次记录。其他模块和既有历史交付不受此规则影响。

## 历史任务整理

先停止项目服务并确认没有活动下载、审批、价格导出或核算。运行项目 Python 的 `scripts/migrate_flat_deliveries.py` 查看计划，`--apply` 执行。仅完整成功的下载任务家族可迁移；失败和待恢复任务保持原位。内部备份包含原目录完整文件、数据库快照及逐文件字节数和 SHA256；所有备份校验通过后才移动。失败时恢复原目录和索引，并保留失败现场。迁移只移除已备份且与成品逐字节相同的生成副本，保留原始资料和过滤输入。工作锁避免与运行实例并行迁移。

`layout_migration/<时间>/journal.json` 记录备份清单、迁移路径和状态。审批回执、价格和核算的历史整理结果另见 `other_deliveries.json`。备份与内部工作目录不计入日常成品目录，不自动删除。

Windows 拒绝重命名原目录时，迁移改用完整复制并逐文件校验，成品发布完成后只移除已备份且未变化的旧副本。复制失败也会回滚；被占用而无法移除的旧文件会记入 `cleanup_pending`，不会强删。
