# 动态目录与功能状态

- 核算和缺失城市映射与下载、专项报表复用风神城市选项；灯塔模式读取灯塔授权目录。移除固定城市数组，目录暂不可读时提示重试。历史停用城市仍可用于复核，下载模块原有停用限制保留。
- 蓝橙价格筛选保留每个站点编号，显示城市和编号。同名候选不能用现有名称筛选唯一定位时要求限定城市或核对，不静默合并站点。
- 平台连接面板显示账号、组织（仅平台确实提供时）和功能范围。成功读取站点目录只证明目录可用，不代表知了/MOA认证或账单下载权限已完成。目录验证记录按会话隔离，五分钟过期。
- 新异常骑手整理任务读取蓝橙官方城市、站点目录并将快照写入工作簿“站点城市目录”。目录读取失败仍保留来源文件中的城市及人工配置，未匹配的归属标为待核对。
- 人工配置与官方目录不一致时保留人工配置，增加“城市归属待核对”子表；不按站名包含的城市猜测未知归属。不改扣款金额、已生成报表及冻结批次。
- 生成前后账号变化会拒绝套用新账号目录；没有覆盖权限的目录项不补造。
