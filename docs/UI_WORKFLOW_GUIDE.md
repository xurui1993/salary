# 工作台界面与操作约定

## 共用样式

`src/workbench-unified.css` 在原布局样式之后加载，统一中文优先的本机字体、标题层级、按钮、表单、表格、抽屉及提示样式。页面不再依赖 Google Fonts 下载。代码、编号及日志仍可使用等宽字体。

新增页面沿用 `.wb-primary`（当前主要操作）、`.wb-button`（次要操作）、`.wb-link`（轻量导航），避免另写一套按钮尺寸及颜色。小屏表格在容器内滚动，城市、资料卡片和报表范围控件保持在视口内。

## 按业务复杂度展示

- 蓝橙、商翼及灯塔档案的固定采集范围使用 `CollectionScope` 展示一行摘要，来源限制按需展开。
- 固定范围页面采用单栏资料选择与底部操作区，省去重复的右侧清单及范围卡片。
- 不使用“全量历史无限制”或“实时快照”推断平台覆盖和时效；范围以账号权限和平台返回结果为准。

## 结果与下一步

`src/lib/taskGuidance.ts` 统一任务状态与操作含义：等待认证→完成验证，待准备资料→准备资料，缺项→补齐资料，就绪→继续核算，结果待核实→核实结果。未知状态明确显示待确认。存在文件不代表任务成功。

任务详情和价格业务使用 `TaskOutcome` 优先展示结果与下一步。已完成的逐项回执默认折叠；未完成事项保持可见。薪资技术日志由用户主动展开，核算异常数量和资料处理入口保留在主流程。

## 模块衔接

- 新下载创建成功后可直接查看本次任务，列表加载后定位对应任务详情。
- 任务中心到价格审批、每日价格导出的跳转携带真实记录编号；历史记录不在最近20项中时也读取指定编号，不自动替换成最新记录。
- 每日价格新增只读 `GET /api/fengshen-downloads/lanorange-prices/exports/{key}`，沿用现有身份和范围校验。
- 仅为现有流程支持的风神/蓝橙资料提供报表与核算入口；不把“全部城市”当作某一个核算城市。不承诺跨模块自动复用所有资料，目标模块继续执行原校验。
- 模板中心提供返回薪资核算的入口；下载模板不会自动创建核算批次。

## 验证范围

前端回归覆盖状态提示、失败与部分完成、未知状态、跨平台跳转范围及固定范围说明。后端接口测试覆盖指定记录、缺失记录及访问控制。浏览器检查使用合成任务并拦截业务写请求，覆盖桌面页面、小屏布局、弹窗及历史记录跳转。

这些检查不替代真实平台下载、审批操作或 Excel/WPS 工资复核。
