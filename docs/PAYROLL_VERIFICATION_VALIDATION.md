# 2026-11-02 兼职薪资核算维护验证

## 本次变更

- 闪购自动优先处理骑手支付绑定，先导出骑手信息，再获取其他依赖资料和配送费。
- 平台验证保持原任务等待，核算页弹出验证窗口，收起后可以重新打开；不自动发送或重发短信。验证码等待不受原登录等待时限影响，用户可停止任务。
- 如果验证或对应导出没有完成，阻止进入工资核算，原始资料保留。等待要求写入下载任务记录，即使前端没有及时轮询到等待状态，也不能静默跳过验证生成工资表。
- 新兼职核算仅交付工资表、蓝橙无单价&未绑名单两份 Excel，不附独立清单文件。复核表嵌入工资表，提供方和状态使用中文，原始摘要及校验码仍保存在内部记录。
- 嵌入复核表仅新增或替换对应 OOXML 工作表部分，原工资工作表、公式、缓存值和样式部分保持原字节。历史文件和其他下载模块沿用原交付方式。
