## 3. 用户故事（按页面组织）

### US-1 数据采集 · 新建采集

作为**发薪专员**，我希望在一个屏幕内完成「选资料 → 选城市/站点 → 选账期 → 开始任务」，这样我不用来回滚动确认自己选了什么。

**验收要点**
1. 1440×900 下，`#step-03-datasets`（选择资料）与 `#step-01-cities`（处理城市与站点）首屏可见区域不重叠且均在 900px 内起始。
2. 右侧 sticky 摘要卡固定显示「已选资料数 / 城市数 / 账期 / 预计任务量 / 开始任务」，滚动时保持可见，高度 ≤ 视口 80%。
3. 摘要卡不再重复列出主区已有的资料条目（当前 `wb-task-form` 右栏重复内容移除）。
4. 任一必填未完成时，「开始任务」呈禁用态并就近说明缺项（不使用全局 toast 代替）。
5. 平台选择器只出现 4 个平台，无重复「灯塔」。

### US-2 数据采集 · 任务中心

作为**发薪专员**，我希望任务表格一眼看出「谁在跑、跑到哪、失败了怎么办」。

**验收要点**
1. 表头顺序：任务/平台 → 状态 → 进度 → 创建人 → 开始时间 → 操作；状态列不再与进度列信息重叠。
2. 状态 pill 只有 5 种语义色（等待/进行中/成功/部分成功/失败），同一状态在全站同色。
3. 操作列右侧固定，横向滚动时不随内容移动。
4. 进行中的行有可见的动效反馈（旋转图标或进度条呼吸），非静态图标。
5. 首屏加载用骨架行，不用「正在读取…」纯文本占满整屏。

### US-3 薪资核算 · 核算批次

作为**发薪专员**，我希望进入页面立刻知道「现在有没有批次、下一步该点哪」。

**验收要点**
1. 无批次时只有**一层**空态卡（外层页容器 + 空态卡），不存在「卡内框内虚线区」三层。
2. 空态卡内并列 3 个动作：上传薪资申请表 / 前往模板中心 / 查看历史批次，点击均到达目标页。
3. 有批次时，批次选择器与「开始核算」在首屏同一水平带内。
4. 页面底部无 >200px 的空白区（容器高度随内容或撑满视口）。

### US-4 薪资核算 · 扣款规则

作为**发薪专员**，我希望从「143 个待配置」直接筛出这 143 个站点，填完就保存，不用整页找按钮。

**验收要点**
1. 工具条统计 pill 可点击，点击后表格只显示未配置站点，pill 变为「已筛：只看待配置 ×」，再点恢复全部。
2. 筛选状态与城市筛选、搜索框可叠加，叠加后显示「当前 N 条 / 全部 M 条」。
3. 平台登录失效时，错误条与主保存按钮同屏（1440×900 无需滚动），错误条内「立即登录平台」可点。
4. 表格高度自适应剩余视口，行数少时不留 >200px 空白，行数多时表头 sticky。
5. 保存成功后原地提示，不跳页、不整页刷新。

### US-5 价格审批

作为**价格审核人**，我希望「没有待办」时也清楚接下来能做什么，而不是看到一整屏空白。

**验收要点**
1. 空态卡文案说明原因（当前筛选无待办 / 需登录蓝橙），并提供「刷新待办」「切换到待审每日价格导出」两个动作。
2. 待办表格与「审批结果」区之间用标题 + 分割线分层，二者视觉权重不同（待办为主，结果为次）。
3. 空态卡高度 ≤ 320px，页面下方不再出现第二个大空白块。
4. 读取中显示骨架/旋转，不显示可点击的禁用按钮组。

### US-6 全局外壳（侧栏 / 头部 / 窄屏）

作为**在笔记本或窄屏上访问的同事**，我希望导航只有一套，且当前所在位置永远清楚。

**验收要点**
1. 侧栏收起后只剩图标（宽度 56–64px），品牌副标题不折行，完整文案进 `title`。
2. 侧栏 3 个一级项 + 子视图 tab + 面包屑，三者不重复表达同一位置（当前「数据采集」在侧栏、子 tab、面包屑各出现一次，需收敛为：侧栏=模块，tab=子页）。
3. ≤768px 时只保留一套页面切换控件，删除重复的 `wb-mobile-nav` 下拉或顶部 tab 其中之一。
4. 头部右侧只有 1 个入口进入平台连接/通知（popover 内再分状态灯与任务）。
5. 首屏背景色与主题一致，无暗→浅跳变。

## 4. 交互与视觉要求

### 4.1 视觉翻新方向（整体翻新，不是换皮）

**色调**
- 中性基底：`--wb-bg: #F6F7F9`、`--wb-surface: #FFFFFF`、`--wb-border: #E3E6EB`、`--wb-text: #1B2430`、`--wb-text-muted: #5B6573`。
- 主色收敛为**一个**：`--wb-primary: #0F6E8C`（深青蓝，替换现散落的 `sky-600/700`、`indigo-500`），hover `#0C5C75`，浅底 `#E8F2F6`。
- 状态色语义（全站唯一映射）：
  - 成功 `#1F8A5B`、警告 `#B7791F`、危险 `#C0392B`、进行中 `#0F6E8C`、中性 `#5B6573`。
  - 状态 pill 统一「浅底 + 深字 + 无边框」，禁止同状态在不同页面用不同色（当前 `emerald/amber/rose/sky` 混用且部分带边框）。
- 禁止出现：紫蓝渐变、纯黑文字块、超过 2 种强调色同屏。

**圆角 / 阴影 / 间距节奏**
- 圆角三档：`--r-sm: 8px`（输入、pill）、`--r-md: 12px`（卡片）、`--r-lg: 16px`（弹层/抽屉）。禁止 6px/10px/14px 等中间值。
- 阴影两档：`--sh-1: 0 1px 2px rgba(16,24,40,.06)`（卡片）、`--sh-2: 0 8px 24px rgba(16,24,40,.12)`（弹层）。卡片默认**无边框 + 单层浅阴影**，不再「边框 + 阴影 + 内框」三重描边。
- 间距只允许 `4 / 8 / 12 / 16 / 24 / 32`；卡片内 padding 统一 16（紧凑区 12），页面左右 padding 24（≤1024 为 16）。

**层级与字号**
| 角色 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| 页面标题 | 16px / 600 | 面包屑当前项 |
| 区块标题 | 13px / 600 | 卡片 header |
| 正文 / 控件 | 13px / 400 | 表格、表单 |
| 辅助说明 | 12px / 400，`--wb-text-muted` | 说明、时间戳 |
| 数字 | 13px / 500，`tabular-nums` | 统计、金额 |

### 4.2 信息层级规则（硬约束）

1. **每屏 ≤2 层容器**：页面底 → 功能卡片。卡片内只允许用「分组标题 + 分割线」分隔，不再套第二张卡片或虚线框。
2. **一屏一主操作**：每张卡片右侧最多 1 个主按钮（实心），其余为次级（描边）或文字按钮。
3. **重复信息只留一处**：同一信息（已选资料、平台状态、任务进度）在主区与右栏只出现一次；右栏只放「不随主区滚动而消失的决策信息」。
4. **状态先于详情**：列表行第一列承载标识（编号/名称），第二列承载状态；失败原因就地展开，不弹全局 toast。
5. **警示就近**：错误/警告条与它影响的操作按钮距离 ≤1 屏高，禁止警示在页顶、操作在页底。

### 4.3 空态与加载态规则

- **空态**：单卡 + 线性图标（24px）+ 一句原因（≤30 字）+ 1–2 个动作按钮。禁止「只写暂无数据」；禁止空态卡内再套容器。
- **加载态**：
  - 表格/列表首屏：3–5 行骨架（`--wb-border` 灰块 + 轻微 shimmer）；
  - 按钮内：`Loader2` 14px 旋转，文案改为「正在…」；
  - 页面级任务：进度条 + 百分比，禁止只有转圈无进度。
- **动效**：所有 loading 动画时长 0.8–1.2s 线性无限循环；仅在 `@media (prefers-reduced-motion: reduce)` 下关闭。删除全局 `animation:none !important`。

### 4.4 窄屏规则

断点只允许三个：`1280px`、`1024px`、`768px`（原 12 种全部收敛）。

| 断点 | 行为 |
| --- | --- |
| >1280 | 侧栏展开 240px；采集页双栏（主区 + 右栏 320px） |
| 1024–1280 | 侧栏收为图标栏 64px；采集页右栏改为顶部摘要条 |
| 768–1024 | 单栏；表格横向滚动，首列 sticky；卡片 padding 12 |
| <768 | 侧栏为抽屉（汉堡开合）；一套页面切换控件；工具栏按钮折为「更多」菜单 |

窄屏不隐藏任何**操作**，只隐藏**重复的描述性文案**（副标题、帮助句）。
