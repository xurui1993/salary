## 4. 不通过项清单（含复现步骤与期望值）

### N1 · V2 sticky 摘要卡在 1024 下失效（中）

**复现**：1440 或 1024 打开 → 平台登录 →「数据采集 / 新建采集」→ 勾选任一资料 → `window.scrollTo(0, document.body.scrollHeight)`。

**实测**：`.wbx-rail__card` 计算值 `position: sticky; top: 68px`，其父 `.wbx-rail` 为 `position: relative`，**父高 298px = 卡片高 298px**。滚动 191px 后卡片 `top = -119`、`bottom = 179`（视口 768），标题「执行规则与摘要」完全滚出视口 → 只看到卡片下半部分。

**根因**：sticky 元素的包含块高度恰好等于自身高度，**无位移行程**，sticky 声明等于空转。

**期望**：1024 下滚动到底时摘要卡 `top >= 68`、`bottom <= innerHeight`，即整卡恒在视口内。修法方向：把 sticky 提到 `.wbx-rail` 上并保证其高度 > 卡片高度（或右栏 `align-self: stretch` + 卡片 `top: 68px`）。

**证据**：`qa-t3/sticky-1024x768-top.png`（未滚动）、`qa-t3/sticky-1024x768-scrolled.png`（滚到底，卡片标题已不可见）。

> 注：1440×900 页高恰为 900（`maxScroll = 0`），无法产生滚动，sticky 在 1440 不可验证（只能判「无滚动时恒在视口内」）；375 下卡片位于页面底部，滚动到底时恰好可见，属自然位置而非 sticky 生效。

### N2 · V15「清空」无二次确认（中）

**复现**：采集页勾选任一资料（`已选 1 / 15`）→ 点击右栏右上角「清空」。

**实测**：点击后立即 `已选 0 / 15`，全程 **无 `Page.javascriptDialogOpening`、无 `[role=dialog]`/modal**（已注册对话框监听并自动取消，未捕获任何事件）。清空后按钮本身消失（未选中时无「清空」按钮），属状态收敛但**不满足「二次确认或明确禁用态」**。

**期望**：点击「清空」后弹出确认（或改为「清空」仅在 ≥2 项时可用 + 提供撤销）。若产品判定该项为低危可接受，请在 PRD V15 中显式豁免，否则仍需补确认。

### N3 · V14 任务中心仍有 1 处「边框 + 阴影 + 内层卡」（轻）

**复现**：「数据采集 / 任务中心」。

**实测**：`tc-center` 元素（1152×752）`border: 1px solid rgb(226,232,240)` + `box-shadow: rgba(15,23,42,0.03) 0 1px 2px`，内含 `wbx-table-scroll wbx-taskcenter__scroll`（自身带边框+圆角+底色的卡）→ 命中「边框 + 阴影 + 内层卡片」。
另有 2 处 `.wb-datepicker-trigger`（246×40）同时带 `border: 1px solid rgb(203,213,225)` 与 `box-shadow: rgba(15,23,42,0.03) 0 1px 2px`，内层为 `.wb-dp-trigger-icon`（非真卡，属「边框+阴影」双重描边但不构成三层）。

**期望**：外卡去掉 `box-shadow`（或去掉 border），或让内层 `wbx-table-scroll` 不再自带边框/底色，二者只留一层描边。

**对照**：采集页 V14 通过 —— 最大卡片嵌套 3 层但仅 2 个文本节点沾边；`.wbx-step` 实测 `border: 0px none` + `box-shadow: rgba(16,24,40,0.06) 0 1px 2px` + `radius: 12px`，确为**单层卡**（"步骤卡改单层卡"成立）。
