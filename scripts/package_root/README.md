# 薪酬工作台源码包

本包只包含应用源码、项目文档和内置标准模板，不包含业务配置、上传资料、核算结果、平台登录会话、依赖或构建产物。

解压后目录：

```text
薪酬工作台/
  启动系统.cmd
  README.md
  app/
  docs/
```

## 首次启动

1. 在Windows安装Node.js 24或更新版本、Python 3.11或更新版本，确保 `node`、`npm` 和 `python` 可从命令行运行。
2. 双击“启动系统.cmd”。它固定进入本包 `app/start.ps1`，首次启动时按项目既有脚本创建虚拟环境、安装依赖并构建。
3. 启动完成后访问 `http://localhost:3000`。首次安装依赖需要网络；系统使用前端3000、后端8009端口。
4. 在新环境重新设置所需业务配置并完成平台登录。不要把源码包当作包含历史业务资料的备份。

应用说明见 `docs/`。内置标准模板位于 `app/system_templates/`。

## 完整性核对

- `docs/SOURCE_MANIFEST.json` 列出源码文件大小、SHA256和打包时的Git提交号。
- `docs/SHA256.txt` 覆盖源码文件及清单本身；ZIP外同名 `.verification.json` 记录整包SHA256、CRC、逐文件摘要和全新解压验证结果。
- 对文件的修改会改变摘要。保留未修改的源码包，另在工作副本开发。

打包器只读取当前仓库，不读取上级目录中的其他项目资料，也不会写回原业务数据目录。
